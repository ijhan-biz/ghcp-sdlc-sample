# Governance Policy (Standard + Conditional Exception)

## 표준 경로
- 기본 개발 경로는 GitHub-native SDLC를 사용한다.
- 모든 PR은 CODEOWNERS 리뷰와 Required checks를 통과해야 한다.

## 조건부 예외
- 예외는 목적, 기간, 비용 상한, 데이터 경계를 명시한 경우만 허용한다.
- 예외 승인은 Tech Lead + Security가 공동 승인한다.

## 금지 항목
- 민감정보, 고객정보, 운영 원문 로그를 AI 입력으로 사용 금지
- 승인되지 않은 외부 도구로 코드/데이터 반출 금지

## 감사
- AI-assisted 라벨, 증적 링크, 승인 로그를 90일 이상 보존한다.
